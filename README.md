# CAMI: Benchmarking Taxonomic Profilers

Результаты  таксономического профилирования на данных 
**CAMI III Toy Human Gut** (образец `sample_0`).

## Использованные инструменты
1. **Kraken2(v2.1.2) + Bracken(v3.1)**
2. **Centrifuge(v.1.0.4.2)**
3. **motus** (v3.1.0)
*(MetaPhlAn, Kaiju, DIAMOND, KrakenUniq не вошли в финальное сравнение из-за ограничений памяти)*

##Данные
- **Риды:** CAMI III Toy Human Gut, образец `sample_0` (16 633 513 прочтений имеют длину ровно 150 нуклеотидов)(пар R1+R2 = 33 266 026).
- **Золотой стандарт:** `taxonomic_profile_0.txt`  .

##Пайплайн
Все команды, которые использовались для скачивания баз, запуска инструментов и конвертации результатов в формат CAMI, находятся в файле **[scripts/README_commands]**.

Краткая схема:
1. Установка методов и их референсных баз 
2. Запуск Kraken2, Centrifuge, mOTUs на парных ридах.
3. Запуск Bracken на результатах Kraken2.
4. Конвертация результатов mOTus автоматическая при запуске алгоритма.
5. Конвертация выходов Kraken2+Bracken и Centrifuge в формат CAMI с помощью `TaxonKit`.
6. Оценка всех профилей против золотого стандарта с помощью **OPAL**.

## Результаты оценки (OPAL)
Оценка на четырех таксономических рангах: `order`, `family`, `genus` и `species`. 

### Сводная таблица метрик (F1-score / Purity / Completeness)

| **mOTUs** | 0.464 / **1.0** / 0.302 | 0.475 / **0.923** / 0.32 | 0.40 / **0.952** / 0.253 | 0.293 / **0.849** / 0.177 |

*(Формат: F1-score / Purity (Чистота) / Completeness (Полнота))*

### Основные выводы:

1. **Падение точности с понижением ранга:** Для всех без исключения инструментов метрики (особенно F1-score) закономерно снижаются при переходе от `order` к `species`. 
2. **Kraken2 + Bracken (Максимальная полнота):** 
   * Показал лучший **F1-score на всех рангах** и наивысшую полноту (Completeness). Он находит больше всего реально присутствующих таксонов.
   * **Проблема:** Обладает низкой чистотой, точностью.
3. **mOTUs (Максимальная чистота):** 
   * Абсолютный лидер по чистоте (**Purity от 1.0 до 0.849**). Если mOTUs предсказывает вид, то он почти наверняка там есть (всего 8 ложных срабатываний на уровне species).
   * **Проблема:** Очень низкая полнота(Recall). На уровне видов он пропустил **209** истинных таксонов из 254 возможных
4. **Centrifuge:** На нулевом sample уступает Bracken по способности находить таксоны, и уступает mOTUs по точности. На ранге `species` его метрики (F1 = 0.227) показывают, что он с трудом справляется с видовой идентификацией в этом датасете.

### Общий рейтинг (Rankings)
Согласно встроенному рейтингу OPAL (сумма баллов по всем метрикам: Completeness, Purity, L1 norm, UniFrac), распределение мест следующее:
1. **sample_0_bracken.cami** (12 баллов)
2. **sample_0_motus.cami** (19 баллов)
3. **sample_0_centrifuge.cami** (26 баллов)

**Итог:**. **Bracken** подойдет для максимального охвата (даже с риском ложных видов), а **mOTUs** для задач, где критически важна точность и отсутствие ложных срабатываний. **Centrifuge** же является чем-то средним между двумя методами.

Полный интерактивный отчет OPAL (с графиками, рейтингами) доступен  в файле **[results/results.html](results/results.html)**.
